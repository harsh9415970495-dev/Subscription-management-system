# /phase-start Workflow

## Steps
1. **Read Implementation Plan:**
   - Open and read the relevant phase section in `docs/IMPLEMENTATION_PLAN.md`.
2. **Re-state Scope:**
   - Outline the goals, backend modules, frontend screens, and exit-gate items for the phase.
3. **Draft Implementation Plan Artifact:**
   - List the explicit task sequence, files to create/modify, test commands, and verification criteria.
4. **Human Review Gate:**
   - Stop and wait for the human reviewer to approve the plan before writing any code.
